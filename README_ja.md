# Multi-Noise Player for AtomS3 Lite

AtomS3 Lite用のマルチノイズジェネレーターです。ピンクノイズ、ブラウンノイズ、ホワイトノイズを切り替えて再生できます。

## 特徴
- 3種類のノイズ（ピンク、ブラウン、ホワイト）をリアルタイム生成
- AtomS3 Lite本体のボタン操作で直感的にコントロール
- LEDカラーと呼吸エフェクトによる状態表示
- 小音量時の聴感補正（ラウドネス補正）

## 操作方法
- **シングルクリック**: 停止 → ピンクノイズ → ブラウンノイズ → ホワイトノイズ → 停止 ... (順次切り替え)
- **ダブルクリック**: 再生/停止の切り替え（すぐに停止させたい場合に便利です）
- **長押し (1秒以上)**: 音量の調整（長押ししている間に1500～100で音量が変化します。お好きなところで離してください）

## LEDインジケーター
- **緑 (点灯)**: 停止状態
- **ピンク (呼吸)**: ピンクノイズ再生中
- **青 (呼吸)**: ブラウンノイズ再生中
- **白 (呼吸)**: ホワイトノイズ再生中
-**黄**：音量調整中
※ラウドネス補正が入っています。
